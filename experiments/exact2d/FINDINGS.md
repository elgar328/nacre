# exact-2d 실험 findings (checkpoint 1)

오버홀의 핵심 novel 메커니즘을 2D 격리 샌드박스에서 선검증한 결과다. 목적은 "빅뱅 재작성"
전에 **되는 것·안 되는 것·비용**을 실측하는 것(overhaul 계획). 커널(main·`overhaul`)은 무변경,
`experiments/exact2d/`는 워크스페이스 비-member로 완전 격리, 26 테스트 그린.

`plan`의 다섯 가설을 위험 우선(H1 → H1.5 → H4 → H2/H3 → H5)으로 검증했다.

## 판정 요약

| 가설 | 판정 | 한 줄 |
|---|---|---|
| **H1** 유리수 치수·각도 | ✅ 참 | exact 누적·닫힘, 90°계열 exact 회전; i128 오버플로는 강등 신호 |
| **H1.5** 고정밀 삼각 게이트 | ⚠️ **의존 변경** | twofloat **탈락** → `astro-float` 채택 |
| **H4-soundness** tol 공식 | ⚠️ **공식 교정** | 접선형 **반증** → 좌표혼합 `(|x|+|y|)·da` |
| **H4-consistency** | ✅ 참 | 경로-독립, 필터=고정밀; **서드파티 버그 발견** |
| **H4-amplification** | ✅ 참(조건) | 번들링 **필수**, 폭발해도 sound |
| **H4-speed** | ✅ 참 | 필터 ~11ns·100% 성공, 상승 ~162µs(드묾) |
| **H2/H3** 명시 공유 | ✅ 참 | 참조 정체성, 우연 일치 별개, O(1) 공면 |
| **H5** op-log | ✅ 참 | replay 결정적; provenance raw vs 의미론 A/B |

**총평: 다섯 가설 모두 2D에서 성립** — 단 H1.5는 의존 라이브러리를, H4-soundness는 tol 공식을
교정해야 했다(둘 다 실험이 아니었으면 3D에서 조용히 틀렸을 것). ⟹ 오버홀은 빅뱅이 아니라 이
메커니즘의 3D 이식 + 사이드카 점진 은퇴로 정당화된다.

## H1 — 유리수 치수·각도 (✅ 참)
- **exact 누적**: `1/10` 10회 = 정확히 1(f64는 0.999…); `11/10 × 7 = 77/10`(f64 `1.1×7 ≠ 7.7`).
- **각도 닫힘**: `360/7° ×7 = 정확히 0`, `1/3° ×1080 = 0`(드리프트 0).
- **90°계열 exact 회전**(놀란 점, 추가 발견): 0/90/180/270°는 cos/sin ∈ `{0,±1}`(Niven)이라 회전이
  **유리수 exact(tol 0)**. 축정렬 exact 영역이 "축정렬 + 90°계열 회전"까지 확장.
- **비용/한계**: `Ratio<i128>` 고정폭. 적대적 coprime 분모 누적에서 **~122비트**(소수 25개)에 오버플로 →
  §4 강등 신호. 정상 사용과는 먼 거리 → i128 + 강등이 실용적.

## H1.5 — 고정밀 삼각 게이트 (⚠️ 의존 변경: twofloat → astro-float)
- **twofloat(double-double) 탈락**: π 상수는 정확하나 삼각함수가 "preliminary" — 내재 `cos²+sin²−1
  ≈ 5.3e-22`, **영점 근처 절대오차 ~1.8e-16(f64 수준)**. 판정이 부호를 정하는 near-degenerate가 곧
  영점 근처라 치명적 → ~1e-30 게이트 **실패**.
- **astro-float(순수 Rust 임의정밀) 채택**: 160비트에서 cos/sin 오차 **~1e-58**로 통과. **정밀도 dial
  가능** → double-double의 ~1e-32 천장이 사라짐(H4-amplification의 "quad-double or 거절" 딜레마 해소).
- **비용**: 상승당 ~120µs(H4-speed 참조). 드문 상승 경로라 감당, 각도당 캐시로 상각.
- **놀란 점**: 문서상 채택 예정이던 라이브러리가 정확도 게이트에서 탈락. fail-fast의 값어치.

## H4 — TIP (핵심·최대 위험, 전부 검증)

### soundness (⚠️ 공식 교정)
- **접선형 새-오차 공식 `da·|모멘트암|` 반증**: 좌표 하나가 0 근처면 과소평가 → **10000 랜덤 중 220회
  상한 붕괴**(unsound). 원인: 독립 cos/sin 반올림은 순수 회전이 아니라 **방사 성분**(`err_x=|x·δc−y·δs|`)
  을 만드는데 접선형이 이를 놓침.
- **좌표혼합 `(|bx|+|by|)·da`로 교정**: 10000 랜덤 **0회 붕괴**, 스케일 무관, 최악 tightness **0.279**
  (예측이 실제의 ~3.5× 이내 — 타이트해 필터로 유용).
- **전파 항 `|R|·old` 검증**: 증분 회전 체인 5000회 0 붕괴. 필요성은 **비대칭 tol**에서 발현(x-tol을
  90° 회전 → 오차가 y로 이동, 전파 없으면 tol_y=0 과소예측).

### consistency (✅ 참)
- **경로-독립**: 같은 삼각형을 여러 각도로 실현해도 orient2d 부호 동일(CCW→+, 공선→Zero).
- **필터↔고정밀 일치**: 랜덤 2000 삼각형에서 f64 필터와 256비트 판정 **불일치 0**.
- **★ 서드파티 버그 발견**(놀란 점): `astro-float 0.9.5`의 `cmp`가 **0.5 미만 양수를 0보다 작다고 오판**
  (0 우변 피연산자 특수처리 누락 — 알려진 이슈 [#44](https://github.com/stencillogic/astro-float),
  PR #45 미머지). 회피: 부호를 `is_positive()`로. **3D였으면 간헐적 부호 오판으로 디버깅 지옥**이었을 것.

### amplification (✅ 참, 조건: 번들링 필수)
- **번들(§4) 경로**: tol이 좌표 스케일에 선형·실현 횟수 무관. 1km에서도 상승 정밀도 **~75비트**면
  충분(우리 160). ⟹ 증폭이 정확성을 위협 안 함(dial-able).
- **★ 번들 안 하면 지수 폭발**(놀란 점): 증분 실현은 전파 `|R|`(행합 `|cos|+|sin|≥1`)을 매 스텝 곱해
  tol 바운드가 **지수 증가**(30스텝에 실제 오차의 ~20만 배). **실제 오차는 R 노름보존이라 평평.**
  ⟹ **번들링은 최적화가 아니라 필수.** 단 폭발해도 sound 최악-보장이라 조용히 안 틀리고 상승/거절로만.

### speed (✅ 참)
- **필터(흔함, f64): ~11 ns/판정**, 랜덤 5000 중 **상승 0회**(100% 필터 해결).
- **상승(드묾, astro-float): ~162 µs/판정**(~15000×, un-cached). 진짜 near-degenerate에서만 발동 →
  상각 비용 ≈ 필터. 각도당 캐시로 더 감소 가능.

## H2/H3 — 명시 공유 (✅ 참)
- **정체성 = 참조(Handle), not 좌표**: 기존 사각형 위에 "같은 사각형"을 그리면(엣지 Handle 참조)
  **새 점 0·새 선 0**.
- **우연 일치 별개**: 다른 구성으로 같은 좌표에 만든 요소는 **병합 안 됨**(좌표 같아도 다른 Handle).
  치수 편집 시 위상 안 바뀜(전역 자동병합의 TNP 충돌 회피).
- **공면 페이오프**: `coincident(a,b) = (a==b)` — **O(1) Handle 동일성, 좌표 비교 0**.

## H5 — op-log (✅ 참)
- **`Document = Vec<Op>`(진실) + 파생 Sketch**; apply가 모델+로그 동시 갱신, replay가 로그를 접어
  재생성(DNA ③ "model=replay").
- **replay 결정성**: 두 번 replay → 동일 모델(Handle 인덱스까지) + live와 일치.
- **provenance A/B**: raw Handle(위치)은 op 삽입 시 인덱스 밀려 **조용히 오연결**; 의미론적 stable-id는
  **삽입 생존 + 대상 삭제 시 감지**(`broken`) → §7 "감지 후 물음"의 근거.

## 부수 발견 (놀란 점 모음)
1. **90°계열 exact 회전**(H1) — Niven. 흔한 회전(직각)이 exact 영역에 들어옴.
2. **twofloat 삼각 부정확 → astro-float**(H1.5) — 문서 채택 예정 라이브러리 탈락.
3. **접선형 tol 공식 반증 → 좌표혼합**(H4-soundness) — 설계 §TIP의 "남은 수학"을 실측이 교정.
4. **astro-float #44 비교 버그**(H4-consistency) — 0.5 미만 양수 vs 0 오판. `is_positive` 회피.
5. **번들링 필수(지수 폭발)**(H4-amplification) — §4를 정량 강화.

## 2D가 검증한 것 vs 3D에 남은 것 (정직)
**검증(토대)**: 유리수·각도 exact, TIP 필터+상승의 soundness/consistency/속도, 명시 공유, op-log 시너지.
**3D에 남음**(§10 · overhaul §11-B):
- **3-평면 implicit point** — 2D는 2-선 교차라 더 단순. 3D 판정 형태.
- **boolean이 토폴로지-공유 피연산자를 받는 3D 구현** · 다중 솔리드 방출 · **per-solid vs 전역 validate**.
- **provenance 자동 naming**(TNP의 진짜 핵심) — 이번 H5는 참조 **골격**(id로 참조·삭제 감지)만 했고,
  **연산이 생성한 요소에 유래로 자동 이름 부여**(FreeCAD ElementMap의 실체)는 **불리언이 있어야** 하는
  3D 과제. 상용도 완전 해결 못 하는 문제이므로, nacre는 "자동 해소 가능한 건 자동, 애매하면 물음"으로.
- **추이성 붕괴·declare-0 확인의 실무 발생 빈도** — 인위적 재현은 됐으나 실무 통계는 3D·실사용 후.

## 3D 이식 go/no-go (권고)
**GO** — 다섯 가설이 2D에서 성립하고, 두 교정(astro-float·좌표혼합 tol)까지 실측으로 확정됐다.
"빅뱅 재작성"이 아니라 **이 메커니즘의 3D 이식 + 사이드카 점진 은퇴**가 정당하다. 순서(overhaul §9):
2D findings → overhaul.md 갱신 → (5d)#4·#5 마무리 → 생성-시 명시 공유 + 참조-공면 + 2D-프레임 →
TIP(독립-솔리드 회전) → 사이드카 은퇴. 위 "3D에 남은 것"은 이식 단계에서 확인·설계한다(2D 성공을
3D 성공으로 과신하지 않는다).
